# Code Validation & Fix Output

This module validates CSS/React fixes generated by the VLM pipeline.

## Workflow

Task 4 generates and extracts the code.

The validation module then:

1. Checks whether code exists.
2. Checks whether the code type is supported.
3. Checks the code length.
4. Accepts or rejects the generated fix.
5. Produces a structured output for the repair workflow.

## Input

```json
{
    "code_type": "css",
    "code": ".checkout-button { margin-bottom: 20px; }"
}
```
---

## Output

```json
{
    "status": "validated",
    "code": ".checkout-button { margin-bottom: 20px; }",
    "code_type": "css",
    "reason": "Basic validation passed"
}
```

---

# But there's one important thing

**Don't stop here.**

The above is your **first version**. It proves the pipeline works, but "Code Validation" in your project should eventually be more meaningful.

Your final Task 5 should ideally have these layers:

```text
Extracted Code
      ↓
1. Empty check
      ↓
2. Code type check
      ↓
3. Syntax validation
      ↓
4. Basic safety validation
      ↓
5. Generate structured output
      ↓
Repair Workflow
```
